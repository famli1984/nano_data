# Packliste: Sommer Bus-Urlaub

## VW Bus – Pflichtausrüstung
- [ ] Campingtisch + Stühle
- [ ] Kartuschenkocher (Billiggas / EN417-kompatibel) + Kartuschen
- [ ] Geschirr, Besteck, Topf, Pfanne
- [ ] Wasser-Kanister (mind. 10L)
- [ ] Werkzeugkasten + Warndreieck
- [ ] Kabelrolle / Steckdosenadapter (Camping)
- [ ] Campingtoilette / Falttoilette (optional)

## Schlafen
- [ ] Schlafsäcke (je nach Nacht-Temp)
- [ ] Bettlaken / Hüttenschlafsack
- [ ] Kissen oder Reisekissen
- [ ] Dachzelt (falls vorhanden) prüfen

## Kleidung (Sommer)
- [ ] T-Shirts, kurze Hosen
- [ ] Badezeug (2x je Person)
- [ ] Eine Schicht für kühlere Abende
- [ ] Regenjacke

## Kinder
- [ ] Sonnencreme LSF 50+
- [ ] Sonnenhut
- [ ] Wasserflaschen (eigene je Kind)
- [ ] Bücher / Malsachen / Spiele
- [ ] Lieblings-Kuscheltier (Rosa)
- [ ] Drohne
- [ ] Feuerschale

## Lebensmittel-Grundausstattung
- [ ] Frühstück (Müsli, Brot, Aufschnitt-Kühltasche)
- [ ] Snacks für unterwegs
- [ ] Gewürze, Öl, Salz
- [ ] Kaffee-Setup

## Dokumente & Sonstiges
- [ ] Reisepässe / Ausweise
- [ ] KFZ-Papiere, grüne Versicherungskarte
- [ ] Campingcard / Stellplatz-Apps (Stellplatz.info etc.)
- [ ] Erste-Hilfe-Kasten
- [ ] Insektenschutz

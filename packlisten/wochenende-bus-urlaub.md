# Packliste: Wochenende Bus-Urlaub (2–3 Tage)

## Minimalausstattung VW Bus
- [ ] Campingküche + 1 Gaskartuschen
- [ ] Kleines Geschirr-Set
- [ ] Wasser-Kanister (5L)
- [ ] Campingmesser + Schneidebrett

## Schlafen
- [ ] Schlafsäcke
- [ ] Kissen

## Kleidung (je Person, 2–3 Tage)
- [ ] 2 Outfits + Reserve-Unterwäsche
- [ ] Badezeug (falls Wasser geplant)
- [ ] Jacke für Abend

## Schnell-Lebensmittel
- [ ] Frühstück (Brot, Käse, Obst)
- [ ] Snacks
- [ ] Kaffee

## Dokumente
- [ ] Ausweis
- [ ] KFZ-Papiere
- [ ] Erste-Hilfe-Mini-Set

## Kinder
- [ ] 1 Spielzeug / Buch je Kind
- [ ] Sonnenschutz
- [ ] Wasserflaschen

# packlisten – Urlaubs-Packlisten

Packlisten für verschiedene Reisetypen. Als Template verwenden — Checkboxen vor jeder Reise zurücksetzen.

## Dateien

| Datei | Inhalt |
|-------|--------|
| `allgemein.md` | Basischeckliste für alle Reisen (Dokumente, Kinder, Haus vor Abfahrt) |
| `busreise-template.md` | Komplett-Template BusUrlaub (alle Kategorien: Küche, Schlafen, Bad, Medis, Fahrrad, Klettern, Schwimmen, Spielen…) |
| `sommer-bus.md` | Sommer-Busreise mit VW Bus |
| `wochenende-bus.md` | Wochenend-Busreise (2–3 Tage, Minimalausstattung) |
| `winter-urlaub.md` | Winterurlaub / Skifahren |

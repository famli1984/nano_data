# 04 — Decisions

One file per significant decision. Format: `YYYY-MM-DD-topic.md`

Each decision file documents:
- **Context:** What situation prompted this decision
- **Options considered:** What we evaluated
- **Decision:** What we chose and why
- **Open questions remaining:** What's still unclear after deciding

Decisions are permanent records — don't edit them after the fact. Add a new file if we revisit.

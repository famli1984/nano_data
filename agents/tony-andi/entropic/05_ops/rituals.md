# Working Rituals

*How we work together. Cadence, formats, norms.*

*Last updated: 2026-05-10*

---

## Weekly Check-In (30 minutes)

**When:** To be set — suggest Monday morning or Friday afternoon.
**Format:** Video call, async summary in Slack/WhatsApp before the call.

**Agenda:**
1. What did each of us do last week? (5 min each)
2. What's blocking us? (5 min)
3. What are we committing to this week? (5 min)
4. Any decisions to make? (5 min)

**Rule:** If neither of us has anything urgent, we skip the call and do it async.

---

## Monthly Strategy Review (60 minutes)

**When:** Last Friday of the month.
**Purpose:** Zoom out. Are we still building the right thing? What's the trajectory?

**Agenda:**
1. Review the roadmap — what moved?
2. Read the last 3 customer interview notes together
3. One strategic question to discuss (e.g., pricing, positioning, next feature)
4. Update `03_strategy/roadmap.md` if needed

---

## How We Use This Repo

- **Read before writing.** Before adding anything, check what's already there.
- **One file per decision.** Don't append decisions to existing files — create a new `04_decisions/` file.
- **Mark open questions.** Use `> ❓ Question: ...` anywhere. Don't delete them — resolve them with a decision file.
- **Update status.** If something in `roadmap.md` is done, mark it. Don't leave stale tasks.

---

## AI Use

- Both founders use AI in their work — that's expected and fine
- AI-generated content that goes into this repo should be reviewed and owned by the author
- The `CLAUDE.md` file is our shared AI context — update it when the context changes

---

## Working Async

- Use this repo for substantive communication
- Use WhatsApp/Telegram for quick coordination
- Use email only for external parties
- Don't bury important context in chat threads — bring it into the repo

# Customer Interviews

*Folder for notes from conversations with potential customers and users.*

## Format

One file per conversation: `YYYY-MM-DD-name-or-profile.md`

Each file should contain:
- **Profile:** Who they are (not their name if sensitive)
- **Date:** When we spoke
- **Key quotes:** Verbatim or close to it — don't paraphrase the gold
- **Pain confirmed / Pain not confirmed:** What resonated, what didn't
- **Surprising:** What we didn't expect
- **Follow-up:** What we want to explore next

# Kapitel 3: GitHub Copilot einrichten – Schritt für Schritt

> GitHub Copilot läuft direkt auf deinem Computer, gibt dir Zugriff auf alle deine lokalen Dateien und ist im ersten Monat kostenlos. Ideal für einen ersten Pilot-Test.

---

## Warum GitHub Copilot als Einstieg?

Es gibt einfachere KI-Tools (dazu gleich mehr) – aber GitHub Copilot hat einen entscheidenden Vorteil für Lehrkräfte: Er läuft in **Visual Studio Code**, einem kostenlosen Editor, der direkt auf deine lokalen Ordner zugreift. Das heißt:

- Deine Unterrichtsmaterialien liegen auf deinem Computer
- Du gibst der KI Zugriff auf einen Ordner
- Sie liest deine Dateien und arbeitet damit – ohne Upload in eine Cloud

Das erste Monat ist kostenlos. Danach kostet Copilot Pro 10 $/Monat.

> **Tipp für Einsteiger:** Wenn du einfach loslegen willst, ohne Installation, dann starte lieber mit **Claude.ai** (claude.ai) oder **Perplexity** (perplexity.ai) – beide funktionieren direkt im Browser. GitHub Copilot lohnt sich besonders, wenn du lokal mit eigenen Dateien arbeiten möchtest.

---

## Was du brauchst

- [ ] Einen Computer (Windows, Mac oder Linux)
- [ ] Eine E-Mail-Adresse
- [ ] Einen GitHub-Account (kostenlos)
- [ ] Visual Studio Code (kostenlos)
- [ ] Ca. 20–30 Minuten Zeit

---

## Schritt 1: GitHub-Account erstellen

1. Gehe auf **github.com**
2. Klicke auf **„Sign up"** (oben rechts)
3. Gib deine E-Mail-Adresse ein und wähle einen Benutzernamen
4. Bestätige deine E-Mail-Adresse über den Link, den GitHub schickt

> Du brauchst keine Kenntnisse in Programmierung – GitHub ist eine Plattform für Code, aber du nutzt hier nur den KI-Assistenten.

---

## Schritt 2: Visual Studio Code installieren

1. Gehe auf **code.visualstudio.com**
2. Lade die Version für dein Betriebssystem herunter (Windows / Mac / Linux)
3. Installiere das Programm wie gewohnt (Setup-Assistent führt dich durch)

Visual Studio Code (kurz: VS Code) ist ein kostenloser Editor – du kannst ihn dir wie eine leere Seite vorstellen, die du für viele Dateitypen nutzen kannst: Texte, PDFs, Word-Dokumente und mehr.

---

## Schritt 3: GitHub Copilot aktivieren

### 3a – Copilot-Abo starten

1. Melde dich auf **github.com** mit deinem Account an
2. Klicke oben rechts auf dein Profilbild → **„Settings"**
3. Links im Menü: **„Copilot"**
4. Klicke auf **„Start free trial"**
5. Wähle **„Copilot Pro"** (kostenlos für 30 Tage, danach 10 $/Monat)
6. Hinterlege eine Zahlungsmethode (wird erst nach dem Testzeitraum belastet)

### 3b – Copilot-Erweiterung in VS Code installieren

1. Öffne Visual Studio Code
2. Klicke links auf das **Erweiterungen-Symbol** (vier Quadrate)
3. Suche nach: **„GitHub Copilot"**
4. Klicke bei der offiziellen Erweiterung von GitHub auf **„Installieren"**
5. VS Code fragt dich, ob du dich mit deinem GitHub-Account anmelden möchtest → **„Anmelden"** klicken
6. Es öffnet sich ein Browser-Fenster → melde dich mit deinem GitHub-Account an → bestätige die Verbindung

✅ Wenn oben rechts in VS Code ein kleines Copilot-Symbol erscheint, ist alles eingerichtet.

---

## Schritt 4: Ersten Ordner öffnen und loslegen

1. Erstelle auf deinem Computer einen Ordner, z. B. `Unterricht-KI-Test`
2. Lege dort ein paar Unterrichtsmaterialien ab (z. B. eine Textdatei mit einem Lehrtext)
3. In VS Code: Klicke auf **„Datei" → „Ordner öffnen"** und wähle deinen Ordner

Jetzt hat GitHub Copilot Zugriff auf alle Dateien in diesem Ordner.

### Ersten Chat starten

1. Klicke in VS Code auf das **Chat-Symbol** links (Sprechblase mit Stern)
2. Es öffnet sich ein Chatfenster
3. Schreibe z. B.: `Fasse mir den Text in der Datei lehrtext.txt in 5 Sätzen zusammen`
4. Copilot liest die Datei und antwortet

---

## Schritt 5: Verschiedene Modelle ausprobieren

Einer der großen Vorteile von GitHub Copilot: Du kannst verschiedene KI-Modelle auswählen.

Im Chatfenster oben findest du ein Dropdown-Menü zur Modellauswahl. Dort stehen u. a.:
- **Claude Sonnet / Opus** (von Anthropic)
- **GPT-4o** (von OpenAI)
- **Gemini** (von Google)

Du kannst einfach ausprobieren, welches Modell für deine Aufgabe am besten passt.

---

## Hinweis: Einfachere Alternativen

GitHub Copilot ist ein solider Einstieg – aber für viele Lehrkräfte sind diese Alternativen einfacher zu nutzen:

| Tool | Zugang | Vorteil gegenüber Copilot |
|------|--------|--------------------------|
| **Claude.ai** | Browser, kein Download | Sofort einsatzbereit, sehr gute Textqualität |
| **Perplexity** | Browser, kein Download | Internetsuche inklusive, kostenlos startbar |

Diese Tools brauchen keine Installation. Du gehst einfach auf die Website und legst los.

GitHub Copilot lohnt sich besonders, wenn du:
- Regelmäßig mit **lokalen Dateien** arbeitest
- Verschiedene **KI-Modelle vergleichen** möchtest
- Eine **Integration in deinen Computer** bevorzugst
